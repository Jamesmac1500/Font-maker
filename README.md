# Pixel Font Maker

A self-contained browser app for drawing bitmap-style glyphs on a square grid and exporting them as an installable TrueType font.

Open `index.html` in a browser. Draw characters, preview text, then use **Export TTF**. Install the downloaded `.ttf` on your computer and select the font by name in Word, Pages, Outlook, Gmail, or other apps that use installed fonts.

Project files can be saved and reopened as JSON from the app.

## iPhone

The app includes iPhone home-screen metadata, touch-friendly controls, and a small offline cache. To test it from an iPhone on the same Wi-Fi network, run a local server on the Mac, open the Mac's local network URL in Safari on the iPhone, then use Safari's Share button and choose **Add to Home Screen**.

iOS can download or share the exported `.ttf`, but installing a font system-wide on iPhone normally requires a font/profile utility such as Apple's configuration profile flow or a third-party font installer app. For desktop Word and email clients, installing the exported `.ttf` directly is still the simplest path.
